#Desktop Cat

A Chrome extension that adds a little pixel cat to every webpage. It walks around, sits, naps, and reminds you of things!

---

## What it does

- Walks across the bottom of every page and occasionally sits or lies down
- Gets tired over time and takes naps — clicking it wakes it up and restores energy!
- Delivers reminders via a typed speech bubble
- Five breeds to choose from: Ragdoll, Calico, Orange, Black, Tabby

## How to interact

- **Click** — pet it, plays a happy animation (not available on the version published in Chrome Web Store)
- **Drag** — pick it up and drop it anywhere on the page
- **Popup** — set reminders, switch breeds, or disable the cat entirely

## Reminders

Open the extension pop-up to add reminders. Two modes:

- **Repeat every N minutes** — fires on an interval while you browse
- **At a specific time** — fires once at the time you set each day

The cat will sit down and type your reminder!

## Installation

This extension is available on the [Chrome Web Store](#). You can also load it manually:

1. Go to `chrome://extensions` and enable **Developer mode**
2. Click **Load unpacked** and select this folder
